# Changelog

## 0.1.0
- Première version : communication locale JSON-RPC (`/rpc`) avec la SmartPlug Master.
- Puissance, énergie (kWh intégrés) et statut pour chaque équipement ; interrupteurs pour les prises ETH, SW, TPH.
- Compteur réseau (GMD) signé : énergie importée / exportée.
- Option « appareil de production solaire » : production, réseau, consommation maison.
